❌ 기존 업무 방식 (안타까운 현장)

· 주민이 서류 다 떼어 오셔서 30분 상담했는데 나이 미달 ➔ 주민도 화나고 사회복지사도 거절 시 죄송함
· "저 도배 지원되나요?" 하루에 20번 넘게 똑같은 자격조건 전화 설명하느라 진 빠짐

✨ 셀프 자가진단 도구 (이 기적!)

· 주민이 방문 전 스마트폰으로 4개 질문만 누르면 자격 자동 판정
· 지원 대상자인 경우: "합격! 방문 시 주민등록등본, 신분증 지참" 서류 준비 안내
· 부적격인 경우: 친절하게 이유를 설명하여 서류 떼는 수고 감소

💬 4. 4단계 연속 마스터 프롬프트 (채팅창 복붙 풀패키지)

STEP 1 1차 프롬프트 — 자가진단 질문 및 판정 로직 생성

📋 아래 복사 버튼을 누르고 오른쪽 채팅창에 붙여넣으세요
노인 식사 지원 사업 자격 자가진단 모바일 웹 도구(`index.html`)를 만들어줘.

[진단 질문 4가지]
1단계: "현재 ○○구에 거주하고 계신가요?" (예/아니오)
2단계: "연세가 만 65세 이상이신가요?" (예/아니오)
3단계: "거동이 불편하여 스스로 식사 준비가 어려우신가요?" (예/아니오)
4단계: "현재 다른 기관에서 도시락이나 반찬 지원을 받고 계신가요?" (예/아니오)

[판정 로직]
- 1, 2, 3단계 '예', 4단계 '아니오' ➔ [지원 가능 대상입니다 🟢] 녹색 카드
- 그 외 ➔ [지원 기준 재확인이 필요합니다 🟡] 주황색 카드

질문이 카드 형태로 1개씩 넘어가게 한 개의 `index.html`로 작성해줘.

STEP 2 2차 프롬프트 — 지참 서류 및 전화 상담 버튼 추가

📋 1차 작성이 끝난 후 이어서 적으세요
`index.html` 결과 화면을 업그레이드해줘.

1. [지원 가능 대상] 카드 하단에 "💡 준비 서류: 신분증, 주민등록등본" 박스 포함.
2. "📞 담당 사회복지사와 전화 상담하기"(tel:02-1234-5678) 대형 버튼 추가.

STEP 3 3차 프롬프트 — 다시 진단하기 리셋 버튼 추가

📋 잘못 누른 주민을 위한 처음부터 다시하기 버튼
결과 화면 하단에 "🔄 처음부터 다시 진단하기" 버튼을 만들어서 1번 질문으로 돌아가게 해줘.

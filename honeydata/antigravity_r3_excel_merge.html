🔒 PREMIUM MASTERCLASS R3 (초대형 완전판)

흩어진 명단·엑셀 3초 자동 취합 📊

1동부터 5동까지 제각각 보내온 엑셀 명단 5개, 복사 붙여넣기 하느라 칼퇴 못하셨나요?
한 폴더에 파일들을 쏙 던져놓고 말 한마디면 3초 만에 깔끔한 1개 파일이 완성됩니다.

⏱️ 엑셀 복붙 2시간 -> 3초 중복 신청자 자동 제거 전화번호 하이픈(-) 자동 정제

🌿 1. 사복쌤, 이럴 때 꼭 쓰세요! (현장 비교)

동별·팀별로 양식이 다르게 들어오는 엑셀 취합 노가다를 완전 자동화합니다.

❌ 기존 업무 방식 (야근의 원인)

· 1동은 '성명', 2동은 '신청자'라고 적어 보내서 일일이 제목 고침
· 연락처에 어떤 사람은 `01012345678`, 어떤 사람은 `010-1234-5678` 섞여 있음
· 1동에도 신청하고 3동에도 중복 신청한 사람 눈으로 찾아내느라 2시간 소모

✨ 3초 자동 취합 레시피 (이 기적!)

· 엑셀 파일 5개를 폴더 하나에 쏙 집어넣고 아래 프롬프트 복붙
· 열 이름 자동 통일 + 하이픈 자동 삽입 + 중복 신청자 1초 자동 제거
· 완벽하게 정제된 `통합명단_최종결과.xlsx` 내 바탕화면에 생성!

📁 2. 엑셀 실습 파일 만들기 (1:1 유치원 가이드)

연습용으로 합쳐볼 엑셀 파일 2개를 만들어봅니다.

① 첫 번째 파일 만들기: 엑셀을 켜고 A1, B1, C1 셀에 아래 표처럼 적으세요.

A1 셀 B1 셀 C1 셀
성명 연락처 신청일자
홍길동 010-1234-5678 2026-04-01
김철수 01012345678 2026-04-01

➔ **저장 위치:** 바탕화면 `안티그래비티_연습` 폴더 안에 **`data_files`** 라는 새 폴더를 만들고, 그 안에 **`1팀명단.xlsx`** 로 저장하세요.

② 두 번째 파일 만들기: 새 엑셀 창을 켜고 열 이름을 살짝 다르게 적어보세요.

A1 셀 B1 셀 C1 셀
신청자 전화번호 신청일자
이영희 010-9876-5432 2026-04-02
홍길동 010-1234-5678 2026-04-02

➔ **저장 위치:** 동일하게 `data_files` 폴더 안에 **`2팀명단.xlsx`** 로 저장하세요.

💬 3. 4단계 연속 마스터 프롬프트 (채팅창 복붙 풀패키지)

STEP 1 1차 프롬프트 — 엑셀 자동 취합 & 정제

📋 아래 복사 버튼을 누르고 채팅창에 붙여넣으세요
`data_files/` 폴더 안의 모든 엑셀 파일들을 하나로 합쳐주는 스크립트(`merge.py`)를 만들어줘.

1. '신청자', '이름', '성명' 이라고 되어 있는 열 제목을 모두 '성명' 으로 통일해줘.
2. '전화번호', '핸드폰', '연락처' 라고 되어 있는 열 제목을 모두 '연락처' 로 통일해줘.
3. 연락처에 하이픈(-)이 빠져 있으면 010-XXXX-XXXX 형식으로 자동으로 붙여줘.
4. 성명과 연락처가 똑같은 중복 데이터는 하나만 남기고 삭제해줘.
5. 최종 결과를 `통합명단_최종결과.xlsx` 파일로 저장하고 실행해줘.

STEP 2 2차 프롬프트 — 연령대/지역별 구분 열 추가

📋 1차 성공 후 추가 분석이 필요할 때 입력하세요
`merge.py` 코드를 수정해서 어느 파일(어느 팀)에서 들어온 데이터인지 '출처팀' 열을 추가해서 저장해줘.

🖼️ 4. 결과물 확인 (새로 생성된 엑셀 화면 예시)

📊 새로 생성된 `통합명단_최종결과.xlsx` 열었을 때 모습
성명 (통일됨) 연락처 (하이픈 추가됨) 신청일자
홍길동 010-1234-5678 2026-04-01 (중복 1건 자동 제거!)
김철수 010-1234-5678 2026-04-01 (하이픈 자동 추가!)
이영희 010-9876-5432 2026-04-02

🚨 5. 막혔을 때 1초 해결사! (Troubleshooting)

Q. 엑셀 전화를 불렀더니 010의 맨 앞 '0'이 자꾸 사라져요!

➔ 해결 프롬프트: "연락처 컬럼을 문자열(String)로 읽어서 맨 앞 '0'이 빠지지 않도록 처리해줘."

흩어진 명단·엑셀 3초 자동 취합 📊

1동부터 5동까지 제각각 보내온 엑셀 명단 5개, 복사 붙여넣기 하느라 칼퇴 못하하셨나요?
한 폴더에 파일들을 쏙 던져놓고 말 한마디면 열 이름 통일, 하이픈 자동 삽입, 중복 제거까지 끝난 1개 파일이 3초 만에 완성됩니다.

⏱️ 엑셀 수동 취합 2시간 -> 3초 열 이름(성명/신청자) 자동 통일 중복 신청자 1초 자동 제거 하이픈(-) 자동 정제

🌿 1. 사복쌤, 이럴 때 꼭 쓰세요! (현장 대화록 & 비포 애프터)

동별·팀별로 양식이 다르게 들어오는 엑셀 취합 노가다를 완벽하게 자동화합니다.

김 대리: "박 사복쌤, 5개 동 주민센터에서 보내온 명절 이웃돕기 엑셀 파일 5개 다 합쳐서 관장님 보고서에 넣으셨나요?"
박 사회복지사: "대리님, 1동은 열 제목이 '성명'이고 2동은 '신청자'라고 써서 보내왔어요... 게다가 어떤 동은 전화번호가 `01012345678`이고 어떤 동은 `010-1234-5678`이라서 일일이 고치느라 2시간째 복사 붙여넣기 하고 있습니다 ㅠㅠ"
김 대리: "1동에도 신청하고 3동에도 중복으로 신청한 어르신은 찾았어? 그거 중복 제거 안 하면 지원물품 이중 지급되어서 감사에서 지적받아!"
박 사회복지사: "안티그래비티 IDE에 엑셀 5개를 폴더 하나에 넣고 프롬프트 한 줄만 쳤더니, 열 이름 자동 통일 + 하이픈 자동 추가 + 중복 신청자 자동 삭제된 `통합명단_최종결과.xlsx` 가 3초 만에 만들어졌어요!"

❌ 기존 엑셀 취합 (야근과 오타의 주범)

· 5개 파일 하나씩 열어서 열 제목('성명' vs '이름') 눈으로 맞춤
· 전화번호 `010` 앞 '0'이 빠져서 `1012345678` 로 수정하는 노가다
· 1동과 3동에 이중 신청한 15명의 중복 대상자를 찾느라 눈 충혈

✨ 3초 자동 취합 레시피 (이 기적!)

· 엑셀 파일 5개를 `data_files` 폴더에 던져두고 명령어 복붙
· 열 이름 통일 + 전화번호 하이픈 정제 + 중복 제거 1초 완성
· 깔끔하게 완성된 `통합명단_최종결과.xlsx` 바탕화면에 자동 생성!

📁 2. 엑셀 실습 파일 만들기 (1:1 유치원 가이드)

연습용으로 합쳐볼 엑셀 파일 2개를 만들어봅니다.

① 첫 번째 파일 만들기: 엑셀을 켜고 A1, B1, C1 셀에 아래 표처럼 적으세요.

A1 셀 B1 셀 C1 셀
성명 연락처 신청일자
홍길동 010-1234-5678 2026-04-01
김철수 01012345678 2026-04-01

➔ **저장 위치:** 바탕화면 `안티그래비티_연습` 폴더 안에 **`data_files`** 라는 새 폴더를 만들고 그 안에 **`1팀명단.xlsx`** 로 저장하세요.

② 두 번째 파일 만들기: 새 엑셀 창을 켜고 열 이름을 살짝 다르게 적어보세요.

A1 셀 B1 셀 C1 셀
신청자 전화번호 신청일자
이영희 010-9876-5432 2026-04-02
홍길동 010-1234-5678 2026-04-02

➔ **저장 위치:** 동일하게 `data_files` 폴더 안에 **`2팀명단.xlsx`** 로 저장하세요.

💬 3. 4단계 연속 마스터 프롬프트 (채팅창 복붙 풀패키지)

STEP 1 1차 프롬프트 — 엑셀 자동 취합 & 정제

📋 아래 복사 버튼을 누르고 채팅창에 붙여넣으세요
`data_files/` 폴더 안의 모든 엑셀 파일들을 하나로 합쳐주는 스크립트(`merge.py`)를 만들어줘.

1. '신청자', '이름', '성명' 이라고 되어 있는 열 제목을 모두 '성명' 으로 통일해줘.
2. '전화번호', '핸드폰', '연락처' 라고 되어 있는 열 제목을 모두 '연락처' 로 통일해줘.
3. 연락처에 하이픈(-)이 빠져 있으면 010-XXXX-XXXX 형식으로 자동으로 붙여줘.
4. 성명과 연락처가 똑같은 중복 데이터는 하나만 남기고 삭제해줘.
5. 최종 결과를 `통합명단_최종결과.xlsx` 파일로 저장하고 실행해줘.

STEP 2 2차 프롬프트 — 어느 파일에서 유래했는지 '출처팀' 열 추가

📋 데이터 추적을 위해 파일명을 열로 추가할 때 사용하세요
`merge.py` 코드를 수정해서 데이터가 원래 어느 엑셀 파일에서 왔는지 '출처파일명' 열을 만들어서 포함시켜줘.

🚨 5. 막혔을 때 1초 해결사! (Troubleshooting)

Q. 엑셀을 불러왔더니 010 전화번호 앞 '0'이 숫자로 인지되어 '10-1234-5678'로 표시돼요!

➔ **해결 프롬프트:** "연락처 열을 읽을 때 `dtype=str` 문자열 타입으로 지정해서 맨 앞 '0'이 사라지지 않게 해줘."

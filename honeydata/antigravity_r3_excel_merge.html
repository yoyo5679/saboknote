흩어진 명단·엑셀 3초 자동 취합 📊

1동부터 5동까지 따로 들어온 엑셀 명단 5개, 일일이 열어서 복붙하느라 칼퇴 못하셨나요?
한 폴더에 넣고 말 한마디면 중복까지 알아서 지워진 깔끔한 1개 파일이 완성됩니다.

🌿 1. 사복쌤, 이럴 때 꼭 쓰세요! (왜 필요한가요?)

현장의 현실: "김 대리님, 5개 동 주민센터에서 보내온 어르신 밑반찬 신청 엑셀 명단 하나로 합쳐서 퇴근 전에 제출해 주세요!"
어떤 동은 제목이 '성명', 어떤 동은 '이름'으로 다르고, 전화번호에 하이픈(-)이 빠진 경우도 태반이라 일일이 고치느라 2시간 동안 엑셀 화면만 붙잡고 계셨죠.

이 레시피를 쓰면 일어나는 기적:
엑셀 파일 5개를 폴더 하나에 쏙 던져놓고 아래 프롬프트를 복사해 넣으면, AI가 알아서 제목을 통일하고, 전화번호 하이픈을 붙이고, 중복 신청자를 지워낸 `통합명단_최종결과.xlsx` 파일을 3초 만에 만들어냅니다!

📁 2. 따라하기 1단계: 엑셀 샘플 파일 준비하기

연습용으로 합쳐볼 엑셀 파일 2개를 직접 만들어보겠습니다. 1초도 헷갈리지 않게 알려드릴게요!

① 첫 번째 파일 만들기: 엑셀을 켜고 맨 위 1행 셀에 그대로 적으세요.

A1 셀 B1 셀 C1 셀
성명 연락처 신청일자
홍길동 010-1234-5678 2026-04-01
김철수 01012345678 2026-04-01

➔ **저장 위치:** 바탕화면 `안티그래비티_연습` 폴더 안에 **`data_files`** 라는 폴더를 새로 만들고, 그 안에 **`1팀명단.xlsx`** 이름으로 저장하세요.

② 두 번째 파일 만들기: 새 엑셀 창을 켜고 이번엔 열 이름을 살짝 다르게 적어보세요.

A1 셀 B1 셀 C1 셀
신청자 전화번호 신청일자
이영희 010-9876-5432 2026-04-02
홍길동 010-1234-5678 2026-04-02

➔ **저장 위치:** 동일하게 `data_files` 폴더 안에 **`2팀명단.xlsx`** 이름으로 저장하세요.

💬 3. 따라하기 2단계: 채팅창에 시키기

IDE 오른쪽 채팅창에 아래 프롬프트를 그대로 복사해서 넣으세요.

STEP 1 1차 프롬프트 (자동 취합 지시)

📋 아래 복사 버튼을 누르고 채팅창에 붙여넣으세요
`data_files/` 폴더 안의 모든 엑셀 파일들을 하나로 합쳐주는 스크립트(merge.py)를 만들어줘.

1. '신청자', '이름', '성명' 이라고 되어 있는 열 제목을 모두 '성명' 으로 통일해줘.
2. '전화번호', '핸드폰', '연락처' 라고 되어 있는 열 제목을 모두 '연락처' 로 통일해줘.
3. 연락처에 하이픈(-)이 빠져 있으면 010-XXXX-XXXX 형식으로 자동으로 붙여줘.
4. 성명과 연락처가 똑같은 중복 데이터는 하나만 남기고 삭제해줘.
5. 최종 결과를 `통합명단_최종결과.xlsx` 파일로 저장하고 코드를 바로 실행해줘.
1. 오른쪽 채팅창에 붙여넣고 엔터 채팅창에 넣고 엔터를 칩니다.
2. 보라색 [Approve] 승인 버튼 클릭 AI가 지시를 받아 들고 코드를 쓸 준비를 마치면 승인 버튼을 누르세요. 알아서 3초 만에 파일을 합쳐냅니다!

🎉 4. 결과물 확인 (내 폴더를 열어보세요!)

작업이 끝나고 `안티그래비티_연습` 폴더를 보면 새 파일이 생겨 있습니다!

회의록 생성 프롬프트
📋 기본 회의록 초안
업로드한 회의 녹음 파일을 분석해서 공식 회의록 초안을 작성해 줘. 항목: 일시 / 참석자 / 주요 논의 사항 / 결정 사항 / 후속 과제 및 담당자 문체는 합니다체, 기관장 결재용으로 깔끔하게 정리해 줘.
📋 결정사항·과제만 빠르게 추출
녹음 내용에서 '결정된 것'과 '누가 무엇을 언제까지 해야 하는지'만 뽑아줘. 불필요한 잡담이나 맥락 설명은 빼고 핵심 액션 아이템만 담당자 이름과 기한을 포함해서 정리해 줘.
📋 사례회의 개입 방향 정리
이 사례회의 녹음에서 논의된 클라이언트별 개입 방향을 정리해 줘. 각 클라이언트(이름 대신 A, B, C로 표기)마다: 현재 상황 요약 / 결정된 개입 방법 / 다음 모니터링 시점 표 형식으로 만들어 줘.
📋 녹음에서 특정 내용 검색
이 녹음에서 '긴급복지 지원'과 관련된 내용만 찾아서 정리해 줘. 언제 어떤 맥락에서 언급됐는지, 어떤 결론이 났는지 순서대로 알려줘.

제4장. 유튜브 영상 분석
링크 하나로 강의 내용 완전 흡수

유튜브 영상 URL을 소스로 추가하면 AI가 자막을 읽고 영상 내용을 분석합니다. 1시간짜리 강의를 처음부터 끝까지 안 봐도 핵심만 뽑아낼 수 있습니다.

유튜브 소스 추가 방법
  1. 1
    유튜브에서 분석할 영상 주소 복사 영상 주소창에서 전체 URL 복사 (예: https://youtube.com/watch?v=...)
  2. 2
    NotebookLM 소스 추가 → [유튜브 URL] 선택 소스 추가 팝업에서 유튜브 아이콘 클릭
  3. 3
    복사한 URL 붙여넣기 → 추가 클릭 AI가 자막을 읽어 소스로 등록합니다 (1~2분 소요)
  4. 4
    채팅창에서 질문! 영상 내용을 기반으로 원하는 분석 요청

⚠️ 자막이 없는 영상은 분석 불가!

AI는 영상의 '자막 텍스트'를 읽습니다. 자막이 없거나 자동 생성 자막이 꺼진 영상은 분석이 안 됩니다. 유튜브에서 영상 아래 '자막(CC)' 버튼이 활성화되는지 먼저 확인하세요.

유튜브 영상 분석 프롬프트
📋 영상 핵심 3가지 요약
업로드한 유튜브 영상에서 가장 중요한 내용 3가지만 뽑아줘. 각각 한 문단씩, 현장 실무자가 바로 이해할 수 있는 언어로 설명해 줘. 영상을 안 봐도 핵심을 파악할 수 있는 수준으로 요약해 줘.
📋 우리 기관 적용 방안 분석
이 영상에서 소개된 내용 중 종합사회복지관에서 바로 적용할 수 있는 것들을 골라줘. 각 항목마다 '현재 우리 기관 상황 → 어떻게 적용할 수 있는지 → 예상 효과' 순서로 정리해 줘.
📋 교육 영상 → 직원 배포 학습 자료
이 교육 영상 내용을 팀원들에게 공유할 학습 자료로 만들어 줘. 구성: 영상 개요(3줄) → 핵심 개념 5개(각 1~2줄 설명) → 실무 적용 체크리스트 3개 팀 카카오톡에 공유할 수 있도록 간결하게 정리해 줘.
📋 영상에서 특정 내용 검색
이 영상에서 '아동학대 신고의무' 관련 내용이 나오는 부분을 찾아서 정리해 줘. 강사가 어떤 맥락에서 이야기했는지, 핵심 메시지가 무엇인지 설명해 줘.

🎙️ 녹음 파일 분석
① 기본 회의록 초안
업로드한 회의 녹음 파일을 분석해서 공식 회의록 초안을 작성해 줘. 항목: 일시 / 참석자 / 주요 논의 사항 / 결정 사항 / 후속 과제 및 담당자 문체는 합니다체, 기관장 결재용으로 깔끔하게 정리해 줘.
② 결정사항·과제만 빠르게 추출
녹음 내용에서 '결정된 것'과 '누가 무엇을 언제까지 해야 하는지'만 뽑아줘. 불필요한 잡담이나 맥락 설명은 빼고 핵심 액션 아이템만 담당자 이름과 기한을 포함해서 정리해 줘.
③ 사례회의 개입 방향 정리
이 사례회의 녹음에서 논의된 클라이언트별 개입 방향을 정리해 줘. 각 클라이언트(이름 대신 A, B, C로 표기)마다: 현재 상황 요약 / 결정된 개입 방법 / 다음 모니터링 시점 표 형식으로 만들어 줘.
▶️ 유튜브 영상 분석
④ 영상 핵심 3가지 요약
업로드한 유튜브 영상에서 가장 중요한 내용 3가지만 뽑아줘. 각각 한 문단씩, 현장 실무자가 바로 이해할 수 있는 언어로 설명해 줘. 영상을 안 봐도 핵심을 파악할 수 있는 수준으로 요약해 줘.
⑤ 우리 기관 적용 방안 분석
이 영상에서 소개된 내용 중 종합사회복지관에서 바로 적용할 수 있는 것들을 골라줘. 각 항목마다 '현재 우리 기관 상황 → 어떻게 적용할 수 있는지 → 예상 효과' 순서로 정리해 줘.
⑥ 교육 영상 → 직원 배포 학습 자료
이 교육 영상 내용을 팀원들에게 공유할 학습 자료로 만들어 줘. 구성: 영상 개요(3줄) → 핵심 개념 5개(각 1~2줄 설명) → 실무 적용 체크리스트 3개 팀 카카오톡에 공유할 수 있도록 간결하게 정리해 줘.
🔗 음성 + 문서 조합 분석
⑦ 회의 결정사항 지침 교차 검증
업로드한 회의 녹음에서 결정된 내용들이 함께 올린 지침서 기준에 맞는지 확인해 줘. 규정에 어긋나거나 추가 확인이 필요한 사항이 있으면 구체적으로 짚어줘. 문제없는 사항도 간단히 확인 완료로 표기해 줘.

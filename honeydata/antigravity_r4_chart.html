이용자 현황 통계 그래프 자동 생성 📈

엑셀 명단 파일 하나만 주면, 한글 보고서(HWP/Word)에 즉시 복붙 가능한
선명한 월별·연령별 시각화 그래프 이미지를 자동 생성합니다.

🌿 1. 사복쌤, 이럴 때 꼭 쓰세요! (왜 필요한가요?)

현장의 현실: "김 대리님, 올해 상반기 서비스 이용자 현황 통계 차트 그리셔서 보고서에 넣으세요!"
하지만 엑셀에서 피벗 테이블 만들고 차트 서식 맞추려면 2~3시간이 홀딱 지나가고, 겨우 캡처해서 한글(HWP)에 넣으면 글자가 뭉개지고 깨져서 속상하셨죠.

이 레시피를 쓰면 일어나는 기적:
엑셀 데이터만 준비해두고 명령 한 줄만 치면, 한글 폰트가 절대 깨지지 않는 고화질 차트 이미지(`월별그래프.png`)가 내 폴더에 10초 만에 딱 만들어집니다! 그대로 한글 문서에 복붙하면 끝납니다.

📁 2. 따라하기 1단계: 엑셀 샘플 파일 준비하기

연습용 엑셀 파일을 딱 1개 만듭니다.

엑셀을 켜고 맨 위 1행 셀에 그대로 적으세요:

A1 셀 B1 셀 C1 셀
이용일자 성별 연령
2026-01-15 여 68
2026-02-10 남 75
2026-03-05 여 82

➔ **저장 위치:** 바탕화면 `안티그래비티_연습` 폴더 안에 **`이용현황.xlsx`** 이름으로 저장하세요.

💬 3. 따라하기 2단계: 채팅창에 시키기

오른쪽 채팅창에 아래 프롬프트를 붙여넣으세요.

STEP 1 1차 프롬프트 (그래프 이미지 자동 작성)

📋 아래 복사 버튼을 누르고 채팅창에 붙여넣으세요
`이용현황.xlsx` 파일 데이터를 기반으로 보고서용 그래프 이미지(make_chart.py)를 만들어줘.

1. 월별 총 이용 건수 막대그래프 (`월별그래프.png` 파일로 저장)
2. 이용자 수가 가장 많은 달의 막대는 주황색으로 강조해줘.
3. 한글 글자가 깨지지 않도록 한글 폰트를 적용하고 선명한 고화질 이미지로 저장 후 코드를 실행해줘.

🖼️ 4. 결과물 확인 (내 폴더에 생긴 이미지!)

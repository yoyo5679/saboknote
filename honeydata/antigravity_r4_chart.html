이용자 현황 통계 그래프 자동 생성 📈

엑셀 명단 파일 하나만 주면, 한글 보고서(HWP/Word)에 즉시 붙여넣을 수 있는
선명한 월별·연령별 시각화 그래프 이미지를 10초 만에 그려냅니다.

⏱️ 엑셀 차트 만들기 3시간 -> 10초 한글 폰트 100% 깨짐 방지 최고 실적 달 강조 색상 세팅

🌿 1. 사복쌤, 이럴 때 꼭 쓰세요! (현장 비교)

피벗 테이블 설정과 캡처 시 글씨 뭉개짐으로 고통받던 보고서 작성을 해결합니다.

❌ 기존 차트 그리기 (피로했던 순간)

· 엑셀에서 피벗 테이블 만들고 막대 차트 그리다가 서식 다 깨짐
· 캡처해서 한글(HWP) 문서에 넣으면 글자가 희미하고 뭉개져서 보고서 퀄리티 저하

✨ 10초 선명 차트 생성 (이 기적!)

· 엑셀 파일만 두고 명령 한 줄 ➔ 고화질 이미지(`월별그래프.png`) 생성
· 가장 이용자가 많은 달은 주황색으로 강조 표시 ➔ 관장님 보고서에 복붙하면 완벽!

📁 2. 엑셀 실습 파일 만들기 (1:1 유치원 가이드)

엑셀을 켜고 A1, B1, C1 셀에 그대로 적으세요:

A1 셀 B1 셀 C1 셀
이용일자 성별 연령
2026-01-15 여 68
2026-02-10 남 75
2026-03-05 여 82

➔ **저장 위치:** 바탕화면 `안티그래비티_연습` 폴더 안에 **`이용현황.xlsx`** 로 저장하세요.

💬 3. 4단계 연속 마스터 프롬프트 (채팅창 복붙 풀패키지)

STEP 1 1차 프롬프트 — 고화질 통계 그래프 생성

📋 아래 복사 버튼을 누르고 채팅창에 붙여넣으세요
`이용현황.xlsx` 파일을 읽어서 보고서용 막대그래프 이미지(`월별그래프.png`)를 만들어줘.

1. 월별 이용 건수를 구해서 세로 막대그래프로 표현해줘.
2. 이용 건수가 가장 많은 달의 막대는 주황색으로 강조해줘.
3. 한글 글자가 깨지지 않도록 한글 폰트를 지정하고, 인쇄용 고화질로 저장 후 코드를 실행해줘.

STEP 2 2차 프롬프트 — 연령대별 원형(파이) 차트 추가

📋 연령 분포 그래프도 함께 만들 때 입력하세요
60대, 70대, 80대 이상 '연령대별 이용 비율 원형 차트'(`연령대그래프.png`)도 추가로 생성해줘.

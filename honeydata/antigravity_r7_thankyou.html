후원자 감사 메시지 맞춤 대량 생성 💌

"똑같은 단체 스팸 문자 말고, 내 후원 분야가 콕 짚인 진짜 감동 문자!"
후원자 100명의 엑셀 내역을 바탕으로 개인화 감사 문구를 20초 만에 대량 생성합니다.

⏱️ 100명 맞춤문자 작성 5시간 -> 20초 후원 분야별 감동 멘트 대량문자 사이트 엑셀 업로드 지원

🌿 1. 사복쌤, 이럴 때 꼭 쓰세요! (현장 비교)

❌ 기존 단체문자 (스팸 같은 느낌)

· "감사합니다" 똑같은 스팸 단체문자 발송 ➔ 후원자 반응 차갑고 후원 유지율 저하
· 100명에게 후원 내역(어르신, 아동 등) 넣어서 문장을 다 다르게 쓰기는 불가능

✨ 감동 맞춤문자 생성 (이 기적!)

· 후원자 엑셀 명단 두고 명령 치면 후원 내역이 포함된 맞춤 문구 엑셀 자동 작성
· `문자발송_업로드용.csv` 파일 내보내서 대량 문자 사이트에 올리면 전송 끝!

📁 2. 엑셀 실습 파일 만들기 (1:1 유치원 가이드)

엑셀을 켜고 A1, B1, C1, D1 셀에 그대로 적으세요:

A1 셀 B1 셀 C1 셀 D1 셀
성명 후원분야 후원금액 연락처
김철수 독거어르신 반찬 50,000 010-1111-2222
이영희 결식아동 도시락 100,000 010-3333-4444

➔ **저장 위치:** 바탕화면 `안티그래비티_연습` 폴더 안에 **`후원자명단.xlsx`** 로 저장하세요.

💬 3. 4단계 연속 마스터 프롬프트 (채팅창 복붙 풀패키지)

STEP 1 1차 프롬프트 — 개인화 감동 문구 엑셀 작성

📋 아래 복사 버튼을 누르고 채팅창에 붙여넣으세요
`후원자명단.xlsx` 엑셀을 읽어서 후원자별 맞춤 감사 문구를 만드는 스크립트(`make_msg.py`)를 만들어줘.

[문구 형식]
"안녕하세요 [성명] 후원자님! ○○복지관입니다. 보내주신 [후원분야] 후원금 [후원금액]원 덕분에 이웃들에게 따뜻한 희망이 전달되었습니다. 진심으로 감사드립니다."

문자 대량발송 사이트에 바로 올릴 수 있게 '수신번호', '메시지내용' 두 컬럼으로 구성된 `문자발송_업로드용.csv` 파일로 저장하고 실행해줘.

🖼️ 4. 결과물 확인 (대량문자 사이트 업로드 파일)

💌 새로 생성된 `문자발송_업로드용.csv` 예시
수신번호 메시지내용 (맞춤 문구 자동 작성!)
010-1111-2222 안녕하세요 김철수 후원자님! ○○복지관입니다. 보내주신 독거어르신 반찬 후원금 50,000원 덕분에...
010-3333-4444 안녕하세요 이영희 후원자님! ○○복지관입니다. 보내주신 결식아동 도시락 후원금 100,000원 덕분에...
📌 대량 문자 발송 사이트 활용:
생성된 `문자발송_업로드용.csv` 파일을 뿌리오, 알리고 등 대량 문자 사이트에서 [엑셀 업로드]로 올려주시면 100명 전송 완료!

🚨 5. 막혔을 때 1초 해결사! (Troubleshooting)

Q. 문자 발송 사이트에서 CSV 한글이 깨져서 업로드가 안 돼요!

➔ 해결 프롬프트: "`문자발송_업로드용.csv` 파일 저장 시 인코딩을 `utf-8-sig` 로 지정해서 다시 저장해줘."

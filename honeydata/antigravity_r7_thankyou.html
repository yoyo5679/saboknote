후원자 감사 메시지 맞춤 대량 생성 💌

"똑같은 단체문자 말고, 내 후원 분야가 언급된 진짜 감동 문자!"
후원자 100명의 엑셀 내역을 바탕으로 개인화 감사 문구를 20초 만에 대량 생성합니다.

🌿 1. 사복쌤, 이럴 때 꼭 쓰세요! (왜 필요한가요?)

현장의 현실: "선생님, 연말인데 후원자 100명에게 감사 문자 좀 보내주세요!"
하지만 "감사합니다" 똑같은 문자를 보내면 스팸처럼 보여서 후원자 마음이 헛헛하셨죠. 그렇다고 100명 후원 분야(어르신, 아동 등)를 보며 문자를 다르게 적는 건 불가능했고요.

이 레시피를 쓰면 일어나는 기적:
후원자 엑셀 명단만 넣어두고 시키면, "김철수 후원자님, 어르신 반찬 후원금 5만원 덕분에..." 하고 후원 내역이 콕 짚인 감동 문장이 작성된 문자발송용 엑셀 파일이 20초 만에 만들어집니다!

📁 2. 따라하기 1단계: 엑셀 샘플 파일 준비하기

엑셀을 켜고 맨 위 1행 셀에 그대로 적으세요:

A1 셀 B1 셀 C1 셀 D1 셀
성명 후원분야 후원금액 연락처
김철수 독거어르신 반찬 50,000 010-1111-2222
이영희 결식아동 도시락 100,000 010-3333-4444

➔ **저장 위치:** 바탕화면 `안티그래비티_연습` 폴더 안에 **`후원자명단.xlsx`** 이름으로 저장하세요.

💬 3. 따라하기 2단계: 채팅창에 시키기

STEP 1 1차 프롬프트 (개인화 감동 문구 엑셀 작성)

📋 아래 복사 버튼을 누르고 채팅창에 붙여넣으세요
`후원자명단.xlsx` 엑셀을 읽어서 후원자별 맞춤 감사 문구를 만드는 스크립트(make_msg.py)를 만들어줘.

[문구 형식]
"안녕하세요 [성명] 후원자님! ○○복지관입니다. 보내주신 [후원분야] 후원금 [후원금액]원 덕분에 이웃들에게 따뜻한 희망이 전달되었습니다. 진심으로 감사드립니다."

문자 대량발송 사이트에 바로 올릴 수 있게 '수신번호', '메시지내용' 두 컬럼으로 구성된 `문자발송_업로드용.csv` 파일로 저장하고 실행해줘.

🖼️ 4. 결과물 확인 (대량문자 사이트 올리는 파일)

💌 새로 생성된 `문자발송_업로드용.csv` 예시
수신번호 메시지내용 (맞춤 문구 자동 작성!)
010-1111-2222 안녕하세요 김철수 후원자님! ○○복지관입니다. 보내주신 독거어르신 반찬 후원금 50,000원 덕분에...
010-3333-4444 안녕하세요 이영희 후원자님! ○○복지관입니다. 보내주신 결식아동 도시락 후원금 100,000원 덕분에...
📌 대량 문자 발송 사이트 활용:
생성된 `문자발송_업로드용.csv` 파일을 뿌리오, 알리고 등 대량 문자 사이트에서 [엑셀 업로드]로 올리면 100명 감사 문자 전송이 완료됩니다!

레시피 7 마스터 완료! 🚀

프로그램 신청 안내 모바일 웹페이지 📱

어르신들 글씨 작아서 안 보인다는 전화 이제 그만!
카톡 링크 터치 한 번에 큼직한 글씨 안내문과 전화 연결 버튼이 나오는 모바일 페이지를 5분 만에 완성하세요.

⏱️ 작업시간 3시간 -> 5분 포스터 인쇄비 0원 카톡 터치 즉시 전화연결

🌿 1. 사복쌤, 이럴 때 꼭 쓰세요! (현장 비교)

종이 포스터나 이미지 파일 홍보의 한계를 스마트하게 해결합니다.

❌ 기존 홍보 방식 (속상했던 현실)

· 종이 포스터 만들어서 복지관 로비에 인쇄해 붙임 (인쇄비 지출)
· 단톡방에 포스터 이미지 첨부 ➔ 글씨가 너무 작아서 어르신들이 "선생님, 글자가 하나도 안 보여요" 전화 쇄도
· 전화번호 보면서 직접 숫자 하나씩 누르다가 번호 잘못 누르는 오류 발생

✨ 안티그래비티 모바일 페이지 (이 기적!)

· 카톡으로 주소 링크 하나만 전송 ➔ 어르신폰 맞춤 큼직한 글씨 화면
· 하단에 커다란 [📞 전화로 바로 신청하기] 녹색 버튼 탑재
· 어르신이 버튼 터치 1초 만에 복지관 전화 연결 창이 뜨면서 신청 완료!

🖼️ 2. 완성되면 어르신 스마트폰에 어떻게 보이나요? (미리보기)

아래 프롬프트를 실행하면 내 컴퓨터에 바로 만들어지는 모바일 페이지 실제 모습입니다.

📱 어르신 스마트폰 화면 실물 렌더링 예시

2026 청춘 스마트폰 교실

어르신을 위한 1:1 맞춤 디지털 교육

📅 일시: 매주 화요일 오전 10시 ~ 12시
📍 장소: 복지관 2층 정보화 교육실
👥 대상: 65세 이상 지역 어르신 (선착순 15명)
💰 수강료: 전액 무료
💡 1회차: 카톡 사진 보내기 & 손주와 영상통화
💡 2회차: 버스 도착시간 미리 확인하기
💡 3회차: 병원 예약 및 장보기 앱 활용
📞 전화로 바로 신청하기 (터치)

📁 3. 폴더 준비하기 (유치원생도 따라 하는 1:1 위치 가이드)

어려운 명령어나 환경설정 없이, 바탕화면에 폴더 하나만 만들어두면 준비 끝입니다!

1. 바탕화면에 새 폴더 만들기 바탕화면 빈 곳 우클릭 ➔ [새 폴더] ➔ 폴더 이름을 **`안티그래비티_연습`** 으로 만드세요.
2. 안티그래비티 IDE에서 이 폴더 열기 안티그래비티 IDE 상단 메뉴 [File] ➔ [Open Folder] 누르고 방금 만든 `안티그래비티_연습` 폴더를 선택하세요.
🚨 사복쌤들이 자주 하는 실수 3가지 방지!
1. 폴더 이름에 띄어쓰기나 특수문자를 넣지 마세요 (`안티그래비티_연습` 추천).
2. 이미 다른 프로그램이 열려 있으면 창을 끄고 새 폴더를 지정해 주세요.
3. 인터넷이 연결되어 있는지 확인해 주세요!

💬 4. 4단계 연속 마스터 프롬프트 (채팅창 복붙 풀패키지)

IDE 오른쪽 채팅창에 차례대로 복사해서 입력하세요. AI가 알아서 코드를 써줍니다!

STEP 1 1차 프롬프트 — 뼈대 안내 페이지 만들기

📋 아래 복사 버튼을 누르고 오른쪽 채팅창에 붙여넣으세요
사회복지관 '2026 청춘 스마트폰 교실' 모집을 위한 모바일 안내 웹페이지(`index.html`)를 만들어줘.

[포함할 내용]
1. 상단 제목: "2026 청춘 스마트폰 교실" (파스텔 초록색 바탕)
2. 교육 정보: 일시(매주 화요일 10시), 장소(복지관 2층 컴퓨터실), 대상(65세 이상 15명 선착순), 수강료(무료)
3. 커리큘럼: 1회차 카톡 사진 공유, 2회차 버스 도착 확인, 3회차 병원 예약
4. 하단 버튼: "📞 전화로 바로 신청하기" (클릭 시 02-1234-5678 전화 연결되도록 tel: 링크 설정)
5. 한 개의 `index.html` 파일 안에 글자 크기를 어르신이 보기 쉽게 큼직하게 만들어줘.
관전 팁: 보라색 [Approve] 버튼이 뜨면 누르세요! AI가 "index.html 파일 작성을 진행합니다"라고 하면 [Approve] 버튼을 클릭하세요. 왼쪽 화면에 글자가 호다닥 써지면서 자동으로 파일이 생성됩니다.

STEP 2 2차 프롬프트 — 글자 강조 & 녹색 전화 버튼 세팅

📋 1차 작성이 끝난 후 채팅창에 이어서 적으세요
방금 만든 `index.html`을 어르신들이 더 잘 볼 수 있게 디자인을 다듬어줘.

1. 중요 문구인 '전액 무료', '선착순 15명' 글자에 노란색 형광펜 강조 효과를 줘.
2. 전화걸기 버튼을 화면 하단에 크고 눈에 잘 띄는 초록색 대형 버튼으로 만들어줘.
3. 스마트폰 화면 크기(모바일 리스폰시브)에 딱 맞게 정렬해줘.

STEP 3 3차 프롬프트 — 카톡 공유 시 나타나는 예쁜 카드(OG태그) 추가

📋 카톡 링크 보낼 때 예쁜 제목이 뜨게 해주는 프롬프트
`index.html` 파일 상단에 카카오톡 링크 전송용 오픈그래프(OG) 메타태그를 추가해줘.

- 카톡 제목: [모집안내] 2026 청춘 스마트폰 교실 (무료)
- 카톡 설명: 어르신을 위한 맞춤 디지털 교육! 지금 터치하여 신청하세요.
- 카톡 미리보기 이미지 주소도 기본 템플릿으로 포함해줘.

STEP 4 4차 프롬프트 — 문의 담당자 카카오톡 채널 버튼 추가

📋 전화가 부담스러운 분을 위한 1:1 카톡 상담 버튼 추가
`index.html` 하단 전화 버튼 옆에 "💬 카카오톡으로 문의하기" 노란색 버튼도 추가해줘.

🚨 5. 막혔을 때 1초 해결사! (Troubleshooting 5선)

AI 지시 중 문제가 생기면 이 문장을 그대로 복사해서 채팅창에 넣으세요.

Q1. AI가 갑자기 이상한 빨간 글씨 오류를 내면서 멈췄어요!

➔ 해결 프롬프트: "방금 발생한 오류를 수정하고 `index.html` 파일을 다시 완성해줘."

Q2. 전화걸기 버튼을 눌렀는데 반응이 없어요!

➔ 해결 프롬프트: "전화걸기 버튼의 href 주소를 `tel:02-1234-5678` 로 확실하게 고쳐줘."

Q3. 스마트폰에서 볼 때 글자가 옆으로 깨지거나 잘려요!

➔ 해결 프롬프트: "모바일 화면 폭(viewport 360px)에 맞춰 글자가 자동으로 줄바꿈되도록 CSS를 보정해줘."

🎁 6. 다른 사업에도 바로 쓰는 실무 응용 3선 (확장팩)

스마트폰 교실 외에 다른 현장 사업에도 아래 프롬프트만 복붙하면 즉시 활용 가능합니다!

🛍️ 응용 1: 명절 맞이 바자회·후원물품 배분 안내
사회복지관 '2026 추석 맞이 사랑의 바자회' 모바일 안내 페이지(`index.html`)를 만들어줘. 일시: 9월 15일, 장소: 복지관 마당, 주요 품목: 의류, 떡, 생필품. 하단에 "📞 물품 기부 문의하기" 버튼 포함해줘.
🤝 응용 2: 대학생·지역주민 자원봉사자 모집
주말 아동 멘토링 '자원봉사자 모집' 모바일 웹페이지(`index.html`)를 만들어줘. 대상: 대학생 및 성인 봉사자, 활동혜택: VMS 봉사시간 인정, 신청하기 네이버폼 링크 버튼 포함해줘.

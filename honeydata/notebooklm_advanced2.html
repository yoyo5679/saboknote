제1장. 마인드맵이 뭔가요?
지침서를 '지도'로 바꾸는 마법

300페이지짜리 지침서를 처음부터 끝까지 읽을 시간, 사실 없죠. 마인드맵은 그 방대한 내용을 핵심 키워드와 계층 구조로 한 화면에 시각화해주는 기능입니다.

텍스트 vs 마인드맵 — 뭐가 다른가요?
📄 기존 방식

300페이지 지침서를 처음부터 읽음 → 1시간 후 머릿속이 하얗게 됨

🗺️ 마인드맵

소스 업로드 → 버튼 클릭 → 2분 후 전체 구조가 한눈에 펼쳐짐

💡 마인드맵이 특히 유용한 순간

📋

제3장. 마인드맵 실전 활용법
업무별 시나리오 5가지
상황별 활용 시나리오
📅 상황 1 — 새 지침서 배포 당일
지침서 전체 구조를 마인드맵으로 파악 → 팀 공유
✅ 효과: 팀원 전체가 10분 안에 주요 변경사항 파악 완료
🏆 상황 2 — 평가 D-30
평가 매뉴얼 마인드맵 생성 → 영역별 담당자 분배
✅ 효과: "누가 뭘 준비해야 하는지" 한눈에 정리되어 혼선 제거
🎓 상황 3 — 신입 직원 첫날
업무 매뉴얼 마인드맵 출력 → 오리엔테이션 자료로 활용
✅ 효과: 신입 직원이 업무 전체 흐름을 직관적으로 파악
🤝 상황 4 — 사례회의 전 준비
아동학대 대응 매뉴얼 마인드맵으로 개입 단계 정리
✅ 효과: 회의 중 "몇 페이지였더라?" 없이 핵심 절차 바로 확인
📊 상황 5 — 슈퍼비전 준비
관련 지침·사례 기록 마인드맵으로 논점 시각화
✅ 효과: 슈퍼바이저에게 체계적으로 상황 전달 가능
마인드맵 관련 프롬프트
📋 마인드맵 생성 후 특정 영역 상세 분석
마인드맵에서 '예산 편성 기준' 영역이 가장 복잡하게 느껴져. 이 부분만 뽑아서 단계별로 더 자세히 설명해 줘. 초보자도 이해할 수 있도록 예시를 들어서 설명해 주면 좋겠어.
📋 평가 영역별 담당자 분배표 만들기
업로드한 평가 매뉴얼의 전체 평가 영역과 세부 지표를 모두 추출해 줘. 각 영역별로 준비 난이도(상·중·하)와 주요 증빙 서류를 함께 표로 정리해 줘. 우리 기관 담당자가 업무를 나눌 수 있도록 '담당자' 열도 빈칸으로 넣어줘.
📋 신입 직원용 업무 흐름 정리
업로드한 업무 매뉴얼을 바탕으로 신입 사회복지사가 첫 한 달 동안 익혀야 할 핵심 업무 흐름을 정리해 줘. '클라이언트 접수 → 사정 → 계획 수립 → 개입 → 모니터링 → 종결' 순서로 각 단계에서 해야 할 일과 작성 서류를 한눈에 볼 수 있게 표로 만들어 줘.
📄
제4장. 브리핑 문서 심화
목적별로 다르게 뽑는 법

1편에서 브리핑 문서의 기본을 배웠다면, 이번 장에서는 목적에 따라 다르게 요청하는 방법을 배웁니다. 같은 소스라도 프롬프트에 따라 전혀 다른 문서가 나옵니다.

브리핑 문서 3가지 활용 유형
⚡
유형 1 — 빠른 현황 파악용 회의 전 5분 안에 읽을 수 있는 핵심 요약. "이것만 알면 회의 참여 가능"
📊
유형 2 — 의사결정 지원용 선택지·장단점·리스크를 포함한 보고서. 기관장 결재 자료로 적합
🎓
유형 3 — 교육·전달용 어려운 내용을 쉽게 풀어쓴 자료. 주민설명회·팀 교육에 활용
유형별 브리핑 문서 출력 예시
⚡ [유형 1] 빠른 현황 파악용 브리핑
📌 핵심 3줄 요약
• 2026년 아동분야 사업에서 가장 크게 바뀐 것은 소득 기준 완화입니다.
• 기존 중위소득 50% 이하 → 60% 이하로 확대되어 지원 대상이 늘어납니다.
• 신청 서류도 3종 → 1종으로 간소화됩니다.
⚠️ 담당자 즉시 확인 사항
기존 대상자 재심사 필요 여부, 시스템 업데이트 일정, 안내문 재발송 대상 확인

* AI 자동 생성 초안

목적별 브리핑 문서 프롬프트
📋 유형 1 — 빠른 현황 파악용
업로드한 지침서에서 가장 중요한 변경사항 3가지만 뽑아줘. 각 변경사항은 '기존 → 변경 후' 형식으로 한 줄씩 정리해 줘. 회의 5분 전에 읽어도 대화가 가능할 정도로 짧게.
📋 유형 2 — 기관장 의사결정 지원용
업로드한 자료를 바탕으로 기관장님께 보고할 의사결정 지원 문서를 작성해 줘. 구성: 현황 요약 → 선택 가능한 방안 2~3가지 → 각 방안의 장단점 → 추천 방향 A4 1페이지, 합니다체로 작성해 줘.
📋 유형 3 — 주민·보호자 설명용
업로드한 지침서 내용을 복지 제도를 전혀 모르는 일반 주민도 이해할 수 있게 쉽게 설명해 줘. 어려운 행정 용어는 쉬운 말로 바꾸고, 일상적인 예시를 들어줘. "이런 분이 신청하시면 됩니다" "이렇게 신청하시면 됩니다" 형식으로 안내문처럼 작성해 줘.

제5장. 마인드맵 + 브리핑 문서
두 기능을 조합하면 최강!

마인드맵과 브리핑 문서를 순서대로 함께 쓰면 지침서 파악부터 보고 자료 완성까지 한 번에 처리할 수 있습니다.

→
📄 브리핑 문서로 공유용 자료 완성

😩 기존 평가 준비 방식 매뉴얼 전체 읽기(2~3시간) → 지표마다 개별 검색 → 팀장님께 구두로 전달 → 또 잊어버림
↓
✨ 마인드맵 + 브리핑 문서 조합 ① 매뉴얼 소스 업로드

📋 마인드맵 → 브리핑 문서 연계 프롬프트
방금 생성된 마인드맵에서 '서비스 이용자 권리 보장' 영역만 뽑아서 우리 팀 전체에 공유할 브리핑 문서를 만들어 줘. 형식: 핵심 지표 요약 → 준비 서류 목록 → 담당자별 할 일 → 체크리스트 합니다체, A4 1페이지 이내.

업로드한 자료를 바탕으로 기관장님께 보고할 의사결정 지원 문서를 작성해 줘. 구성: 현황 요약 → 선택 가능한 방안 2~3가지 → 각 방안의 장단점 → 추천 방향 A4 1페이지, 합니다체로 작성해 줘.
⑥ 마인드맵→브리핑 문서 연계
방금 생성된 마인드맵에서 '서비스 이용자 권리 보장' 영역만 뽑아서 우리 팀 전체에 공유할 브리핑 문서를 만들어 줘. 형식: 핵심 지표 요약 → 준비 서류 목록 → 담당자별 할 일 → 체크리스트 합니다체, A4 1페이지 이내.

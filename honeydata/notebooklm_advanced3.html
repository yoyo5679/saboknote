제1장. 비교 분석이 왜 중요한가?
매년 반복되는 그 고통

매년 초 새 지침서가 내려오면, 작년 지침서와 일일이 비교하며 달라진 부분을 찾아야 합니다. 한 글자씩 눈으로 비교하다 보면 한두 시간이 훌쩍 지나가죠.

😩 기존 방식 작년 지침서 프린트 → 올해 지침서 프린트 → 나란히 놓고 한 줄씩 비교 → 형광펜 칠하기 → 2시간 경과… 아직도 30페이지 남음

제2장. 소스 세팅 방법
두 지침서를 같은 노트북에!

핵심은 하나의 노트북에 두 파일을 모두 올리는 것입니다. 그래야 AI가 두 문서를 동시에 읽고 비교할 수 있습니다.

소스 세팅 방법 (5단계)
  1. 1
    새 노트북 생성 "2025 vs 2026 아동분야 지침서 비교" 처럼 비교 목적이 드러나는 이름 추천
  2. 2
    작년 지침서 업로드 → 파일명에 연도 표시 예: "아동분야_사업안내_2025.pdf" — 나중에 헷갈리지 않게 파일명을 미리 바꿔두세요
  3. 3
    올해 지침서도 동일 노트북에 추가 업로드 예: "아동분야_사업안내_2026.pdf" — 같은 노트북 안에 두 파일이 모두 있어야 합니다
  4. 4
    소스 패널에서 두 파일 모두 체크 확인 왼쪽 소스 패널에 두 파일이 모두 표시되어야 합니다
  5. 5
    채팅창에 비교 프롬프트 입력 아래 프롬프트를 복사해서 붙여넣고 Enter!

💡 파일명에 연도를 꼭 넣어두세요!

AI에게 "2025년 파일과 2026년 파일을 비교해줘"라고 지시할 때, 파일명에 연도가 있어야 AI가 어느 파일이 어느 연도인지 정확히 파악합니다. 업로드 전에 파일명을 미리 바꿔두세요.

지침서·법령·공문은 공개 자료이므로 업로드해도 무방합니다. 하지만 클라이언트 정보가 담긴 내부 자료를 함께 올리지 않도록 주의하세요.

📋 전체 변경사항 표 추출
업로드한 2025년 지침서와 2026년 지침서를 비교해서 달라진 내용을 모두 표로 정리해 줘. 표 형식: 변경 항목 | 2025년 내용 | 2026년 변경 내용 | 변경 유형(신설/변경/삭제/강화) 중요도가 높은 항목부터 순서대로 정리해 줘.
📋 핵심 변경사항 3줄 요약
두 지침서를 비교했을 때 가장 중요한 변경사항 3가지만 뽑아줘. 각각 한 줄로 "기존에는 ~였는데, 올해부터는 ~로 바뀌었습니다" 형식으로 써줘. 사회복지 현장 담당자가 즉시 이해할 수 있도록 쉽게 설명해 줘.
📋 예산 관련 변경사항만 추출
두 지침서에서 예산 편성, 지원 금액, 집행 기준, 정산 방법과 관련된 변경사항만 골라서 비교해 줘. 금액이 바뀐 경우 얼마에서 얼마로 바뀌었는지 구체적으로 표기해 줘.

제4장. 영향도 분류
"우리 기관에 해당되는 것만" 추출

변경사항을 다 뽑았다면, 이제 우리 기관 상황에 맞게 필터링합니다. 변경사항이 많아도 실제로 우리 기관에 영향을 주는 것은 제한적입니다.

영향도 분류 예시
즉시 대응
긴급지원 조항 신설 — 48시간 내 처리 의무화 기존에 없던 규정이 신설되어 즉시 내부 프로세스 수정 필요. 담당자 지정 및 비상연락망 구축 시급.
즉시 대응
분기별 보고 서식 → 온라인 시스템 전환 기존 서식 사용 불가. 온라인 시스템 계정 발급 및 사용법 숙지 필요.
월내 준비
지원 대상 소득 기준 60%로 확대 기존 대기자 명단 재검토 필요. 확대 대상자 안내문 발송 준비.
참고
지원 단가 인상 (월 6만 → 7.5만원) 예산 집행에 유리한 변경. 기존 예산 계획 조정 검토.
영향도 분류 프롬프트
📋 우리 기관 맞춤 영향도 분류
우리 기관은 종합사회복지관이고 아동급식지원 사업을 운영하고 있어. 앞서 정리한 변경사항 중 우리 기관 업무에 직접 영향을 주는 것만 골라서 '즉시 대응 필요 / 월내 준비 / 참고사항' 3단계로 분류해 줘. 각 항목마다 담당자가 취해야 할 구체적인 첫 번째 행동도 한 줄씩 써줘.
📋 담당자 액션 플랜 생성
지침서 변경사항을 반영해서 우리 기관이 이달 안에 완료해야 할 준비사항을 체크리스트로 만들어 줘. 각 항목마다: 할 일 | 담당 부서 | 완료 기한 | 비고 기한이 촉박한 것부터 순서대로 정렬해 줘.
📋 직원 공지 안내문 초안
지침서에서 바뀐 내용 중 전 직원이 알아야 할 사항만 뽑아서 사내 공지 안내문을 작성해 줘. 제목 포함, A4 반 페이지 이내, 합니다체. 핵심 변경사항 → 우리 기관 대응 방향 → 문의처 순서로 구성해 줘.

제5장. 3개 이상 지침서 동시 비교
3년치 변화 흐름 한눈에 파악

두 개뿐 아니라 3~5개 연도 지침서를 동시에 올려도 됩니다. 3년치 변화 흐름을 보면 정책 방향성까지 읽을 수 있어 프로포절 작성에도 활용됩니다.

다년도 비교 프롬프트
📋 3년치 변화 흐름 분석
업로드한 2024년, 2025년, 2026년 지침서를 모두 비교해서 3년간의 변화 흐름을 분석해 줘. 특히 지원 대상, 지원 금액, 서류 요건이 어떻게 변해왔는지 표로 보여줘. 마지막에는 "이 흐름을 보면 앞으로의 정책 방향은 ___일 것으로 예상된다"는 분석 한 문단도 추가해 줘.
📋 프로포절 정책 흐름 근거 작성
3년간의 지침서 변화 흐름을 바탕으로, 신규 사업 프로포절의 '정책 환경 및 근거' 문단을 작성해 줘. "정부의 ~정책 방향에 발맞추어, 우리 기관은 ~사업을 기획하였습니다" 형식으로 전문적이고 설득력 있게 서술해 줘.
💡 소스 50개 한도 관리 팁

무료 버전 기준 노트북당 소스 50개 한도가 있습니다. 비교 전용 노트북을 별도로 만들어 관리하면 한도를 효율적으로 쓸 수 있어요. 예: "지침서 연도별 비교 전용" 노트북 따로 생성.

제6장. 비교 결과로 공유 자료 완성
팀장·기관장 보고까지 한 번에

비교 분석이 끝났다면 그 결과를 바로 보고 자료로 만들 수 있습니다. 1·2편에서 배운 기능과 조합하면 완성도가 훨씬 높아집니다.

비교 결과 → 보고 자료 변환 흐름
①
비교 표 생성 (3장 프롬프트) 전체 변경사항을 표로 추출합니다
②
영향도 분류 (4장 프롬프트) 우리 기관에 해당되는 것만 필터링합니다
③
팀장 보고용 1페이지 요약 생성 핵심 변경사항 + 대응 방향을 A4 1장으로 압축합니다
④
구글 Docs로 내보내기 → 링크 공유 팀원에게 카카오톡으로 링크 전송, 댓글로 협업 가능합니다
보고 자료 완성 프롬프트
📋 팀장 보고용 변경사항 요약
두 지침서 비교 결과를 팀장님께 보고하기 위한 문서를 작성해 줘. 구성: 제목 → 비교 개요(한 줄) → 주요 변경사항 상위 5개 → 우리 기관 즉시 대응 사항 → 담당자 의견 A4 1페이지 이내, 합니다체, 오늘 날짜 기준으로 작성해 줘.
📋 전 직원 공유용 변경사항 안내문
지침서 변경사항 중 전 직원이 알아야 할 핵심 내용만 뽑아 공지문을 작성해 줘. 길이: 카카오톡 공지 또는 A4 반 페이지 이내 문체: 친근하고 이해하기 쉽게 (딱딱한 행정 문서 느낌 X) "이런 점이 달라졌어요!" 식의 제목으로 시작해 줘.
✅ 2편 기능과 조합하기

변경사항 비교 후 마인드맵(2편)을 추가로 생성하면 전체 구조 변화도 한눈에 파악됩니다. "올해 지침서 전체 구조를 마인드맵으로 만들어줘"로 추가 요청해 보세요.

우리 기관은 종합사회복지관이고 아동급식지원 사업을 운영하고 있어. 앞서 정리한 변경사항 중 우리 기관 업무에 직접 영향을 주는 것만 골라서 '즉시 대응 필요 / 월내 준비 / 참고사항' 3단계로 분류해 줘. 각 항목마다 담당자가 취해야 할 구체적인 첫 번째 행동도 한 줄씩 써줘.
⑤ 담당자 액션 플랜
지침서 변경사항을 반영해서 우리 기관이 이달 안에 완료해야 할 준비사항을 체크리스트로 만들어 줘. 각 항목마다: 할 일 | 담당 부서 | 완료 기한 | 비고 기한이 촉박한 것부터 순서대로 정렬해 줘.
📚 다년도 비교 & 보고 자료
⑥ 3년치 변화 흐름 분석
업로드한 2024년, 2025년, 2026년 지침서를 모두 비교해서 3년간의 변화 흐름을 분석해 줘. 특히 지원 대상, 지원 금액, 서류 요건이 어떻게 변해왔는지 표로 보여줘. 마지막에는 "이 흐름을 보면 앞으로의 정책 방향은 ___일 것으로 예상된다"는 분석 한 문단도 추가해 줘.
⑦ 팀장 보고용 변경사항 요약
두 지침서 비교 결과를 팀장님께 보고하기 위한 문서를 작성해 줘. 구성: 제목 → 비교 개요(한 줄) → 주요 변경사항 상위 5개 → 우리 기관 즉시 대응 사항 → 담당자 의견 A4 1페이지 이내, 합니다체, 오늘 날짜 기준으로 작성해 줘.

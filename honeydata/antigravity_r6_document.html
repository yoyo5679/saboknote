⏱️ 50장 공문 작성 3시간 -> 10초 한 번에 연속 인쇄 지원 A4 1장씩 끊김 설정 완료

🌿 1. 사복쌤, 이럴 때 꼭 쓰세요! (현장 비교)

❌ 기존 공문 작성 (단순 노가다)

· 50명 통지서 만드느라 한글(HWP) 파일에서 이름, 금액 바꿔서 50번 다른 이름 저장
· 금액 오타 나거나 날짜 잘못 적어서 재발송하는 일 발생

✨ 메일 머지 자동화 (이 기적!)

· 엑셀 명단 파일 하나만 두고 시키면 50개 공문서 10초 완성
· `전체_통합인쇄.html` 열어서 `Ctrl+P` 누르면 50명 공문이 A4 1장씩 연속 출력!

📁 2. 엑셀 실습 파일 만들기 (1:1 유치원 가이드)

엑셀을 켜고 A1, B1, C1 셀에 그대로 적으세요:

A1 셀 B1 셀 C1 셀
성명 지원금액 지급예정일
홍길동 500,000 2026-04-15
김철수 300,000 2026-04-15

➔ **저장 위치:** 바탕화면 `안티그래비티_연습` 폴더 안에 **`대상자명단.xlsx`** 로 저장하세요.

💬 3. 4단계 연속 마스터 프롬프트 (채팅창 복붙 풀패키지)

STEP 1 1차 프롬프트 — 개별 공문서 & 통합 인쇄 파일 생성

📋 아래 복사 버튼을 누르고 채팅창에 붙여넣으세요
`대상자명단.xlsx` 엑셀을 읽어서 대상자별 지원금 안내문 공문서(`make_docs.py`)를 만들어줘.

1. 공문 양식 내용:
   - 제목: 2026년 상반기 지원금 결정 통지서
   - 받는 사람: [성명] 귀하
   - 내용: 귀하의 지원금 [지원금액] 원이 [지급예정일] 에 입금될 예정입니다.
2. 50명의 안내문을 한 번에 연속 인쇄할 수 있는 `전체_통합인쇄.html` 파일을 만들어줘.
3. 인쇄 시 대상자 1명당 A4 1장씩 깔끔하게 끊기도록 `@media print` 페이지 분리를 설정하고 코드를 바로 실행해줘.

🖼️ 4. 결과물 확인 (공문 완성과 일괄 인쇄)

📄 완성된 `전체_통합인쇄.html` 예시

2026년 상반기 지원금 결정 통지서

수신: 홍길동 님 귀하

귀하의 지원금 500,000원이 2026-04-15에 지정 계좌로 입금될 예정입니다.

○○사회복지관장 [직인생략]
🖨️ 100장 1초 인쇄 팁:
생성된 `전체_통합인쇄.html`을 브라우저로 열고 `Ctrl + P`를 누르면 모든 대상자 공문이 A4 한 장씩 나뉘어 출력됩니다!
